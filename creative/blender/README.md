# Revive Blender landing animation

Created with Blender 4.5.14 LTS for Intel macOS. Run repair_intro.py in Blender background mode to rebuild the scene, poster and MP4. The script writes ready.txt only after rendering completes. The site keeps its photograph fallback until this marker exists. Playback is manual with native controls and preload=none. No autoplay or flashing.

Art direction: a stylized phone, brushed metallic edges, teal studio, warm brass screen accents, soft area lights and gentle turntable motion. This is an illustrative device model, not a branded device or actual repair demonstration.
